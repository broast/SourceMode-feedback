# SourceMode feedback

This is the public issue tracker for the SourceMode beta.

Use [Report a SourceMode issue](https://github.com/broast/SourceMode-feedback/issues/new?template=bug-report.yml) when a source does not load, a response looks wrong, a conversation loses SourceMode, or something else does not behave as expected.

Before posting, please remove personal information, private conversation content, API keys, and account details from descriptions and screenshots.

The SourceMode implementation is maintained separately from this public feedback repository.
